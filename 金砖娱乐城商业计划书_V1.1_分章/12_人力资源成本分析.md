# 第十二章 人力资源成本分析【V1.2 新增成章】

此前第十章给出了编制、薪酬原则与社会责任，第八章给出了个税代扣，第七章把人力摊进各业态成本率——**数字在、账不成章**。按工作群审阅要求，本章把人力成本单独拉通：编制 → 全口径成本 → 落入损益的位置 → **贵宾厅重点编制** → **机器人 / AI 减员降本** → 对政府就业承诺的交代。

V1.0 / V1.1 损益主表（Y3 营收 $6.40 亿、EBITDA $2.82 亿）**不因本章改写**。本章是成本解剖与运营叠加，节约额作为可实现的上行，不提前计入主表利润。

全口径 $7,540 万 ≈ Y3 营收的 **11.8%**，约占直接运营成本 + 管销费用（$3.59 亿）的 **21%**。对超高端综合体而言，该比例偏紧——前提是贵宾厅人力聚焦、主大厅不堆空桌、后勤尽量自动化。

**结构特征：**

1. **贵宾厅相关人力（荷官 + 监察 + VIP 客服 + 厅内安保）是赌场成本的核心，也是利润的核心**——不在这一块用机器人替代持牌岗位。
2. 外籍礼宾与高管合计约占全口径的 26%，人数只占 6%，是单价最高的两块；应用合同期限、本地接班计划控制，而不是一刀切裁员。
3. 后勤 270 人、餐饮传菜、门禁值守，是机器人替代的主要战场。

## 12.4 贵宾厅人力配置（重点）

利润在 26 个 VIP 厅，不在主大厅人海。厅内设计与编制必须绑在一起。

### 12.4.1 单厅硬件（V1.2 固化）

| 项目 | V1.2 标准 | 说明 |
| :--- | :--- | :--- |
| 厅面积 | 400–450 m² | 沿用第四章 |
| 赌台 | **4 张多功能台** | 每台双面，**4×2 = 8 个作业面** |
| 容量 | 40–50 人 | 8 面可同时开，避免空台 |
| 标配 | 独立收银台、吧台、洗手间套间、管理室、独立监控 | 一厅一闭环 |
| 门禁 | 人形值守机器人 + 机动岗（4:1，见 12.6） | 厅门固定岗不堆人 |

V1.0 写“4–6 张百家乐”的，**以本条 4 张多功能台为准**。台数少、面数够，荷官编制可控，厅内仍显满台。

### 12.4.2 单厅编制（公司直营或合作厅）

三班两倒，每作业面高峰配 1 名荷官，监察跨面巡视。

| 岗位 | 单厅人数 | 是否可由机器人替代 | 备注 |
| :--- | ---: | :--- | :--- |
| 荷官 | 12 | 否（GRA 持牌） | 4 台 × 三班，忙时加面 |
| 监察 / 副场 | 3 | 否 | 跨 8 面 |
| VIP 客服 / 酒水 | 4 | 传菜可机送，接待必须真人 | |
| 厅门值守 | 1 真人机动 + 机器人固定岗 | 固定岗可机替 | 计入安保池，不重复加编 |
| 单厅小计（真人） | **19–20** |  | |

### 12.4.3 26 厅谁出工资

| 厅型 | 厅数 | 厅内荷官 / 客服谁发薪 | 本公司承担（约） |
| :--- | ---: | :--- | :--- |
| 招标厅 | 12 | 承租运营商 | 合规巡视、公共监控、厅门机器人运维 |
| 合作厅 | 12 | 本公司（成本进 25% 运营成本后再分成） | 12 × 20 = 240 人 |
| 自营厅 | 2 | 本公司 | 2 × 20 = 40 人 |
| **公司厅内编制** | **14 厅** |  | **约 280 人** |

420 名荷官编制的构成：厅内约 280 + 主大厅约 90 + 培训备用 / 轮休约 50。主大厅若按 V1.2 改为约 **25 张台**（见 12.4.4），主大厅荷官可从“按 100 台配置”压到约 90 人，**总荷官编制可控制在 360–380 人**，比 10.3.2 的 420 少约 40–60 人，年节约现金约 50–70 万美元。主表暂不下调 420，作为编制上限。

### 12.4.4 主大厅：少台、满台、机器造势

主大厅约 5,000 m² **不再按 100 张台铺满**。空台是最大的人力浪费，也是最差的现场。

| 项目 | V1.0 写法 | V1.2 运营口径 |
| :--- | :--- | :--- |
| 真人赌台 | 约 100 张 | **约 25 张**，开台即满，现场热度优先 |
| 电子牌机 / 马机 | 公司自营约 400 台 | **机器博彩公司投放，利润分成**；造势用，**不是利润中心** |
| 本公司主大厅收入 | 计入 GGR $5,010 万 | 桌游按 25 台缩比；机器只记分成。主表暂保留 $5,010 万，运营预算按分成口径管理 |
| 汇丰 ATM | 未单列 | 场内现金服务由 **汇丰银行 ATM** 提供，减少兑币人力 |

### 12.4.5 泥码赠房（厅与酒店的内部成本）

单次购买泥码 **人民币 2 万元**（约 USD 2,800）赠 **标准客房 1 晚**，次日 16:00 退房，不含迷你吧。

- **出账：** 赌场营运部按内部价向酒店结算房费（建议内部价 = 标准客房 ADR 的 50–60%，约 $175–210 / 间夜）。
- **酒店：** 计入占用，不计入对外 ADR 折扣宣传。
- **人力：** 不新增编制；前厅按普通入住办，赌场客服出赠券。
- **量级：** 若 Y3 主大厅 + 中场客每月 800 笔达标，年结算约 $170–200 万，进赌场客情成本，不进酒店对外营收。

### 12.4.6 VIP 授信人力

大额厅账由**项目方控股的持牌金融服务公司**办理，不在赌场编制内另养一支放贷团队。赌场侧只保留信贷联络 6–8 人，负责对接、KYC 转介与限额执行。该公司独立持牌、独立风控、交易进 AML 系统——政府呈报口径为关联持牌机构，**不采用任何规避监管的表述**。

## 12.5 机器人与 AI：减的是后勤，不是持牌岗位

对标杭州无人酒店的“最少人力模式”，以及大兴机场机器人停车。原则：**固定、重复、低客触岗位用机器；荷官、监察、国宾礼宾、医生必须真人。**

### 12.5.1 替代规则

| 场景 | 人机比 | 原岗位（约） | 保留真人 | 机器岗位 | 净减员 |
| :--- | :--- | ---: | ---: | ---: | ---: |
| 厅门 / 通道门禁 | 人形机 : 机动岗 = **4 : 1** | 200 个固定门岗当量 | 40 机动 | 160 机位 | 160 |
| 餐厅传菜 | 送餐机 : 桌边服务员 = **5 : 1** | 150 个传菜当量 | 25 | 125 机 | 125 |
| AI 停车（大兴机场同类） | 系统值守 + 少数技师 | 40 | 12 | 车位机器人（已在停车楼投资内） | 28 |
| 员工食堂（切菜 / 炒菜 / 面点） | 产线自动化 | 35 | 12 | 烹饪线 | 23 |
| 一站式 AI 洗衣（洗熨整仓） | 产线自动化 | 80 | 25 | 洗衣线 | 55 |
| 客房后勤辅助（布草运送等） | 辅助，不替管家 | 370 客房编制的 15% | — | 运送机 | 55 |
| **合计** |  |  |  |  | **446** |
| 回补：机器人运维 / 调度 |  | 0 | +35 |  | −35 |
| **净减编** |  |  |  |  | **约 411 人** |

减编后稳定期编制约 **3,690 人**。本地化比例维持 73% 以上：减的是重复岗，本地员工转向机务、质检、桌边服务与厅内持牌岗，平均薪酬高于被替代岗位。

### 12.5.2 降本测算（稳健）

| 项目 | 金额（万 USD / 年） |
| :--- | ---: |
| 446 个被替代岗现金薪酬（多为一线，月均约 $500） | 268 |
| 减：新增 35 名运维技师 | −67 |
| 现金净节约 | 201 |
| 加载 25% 后的全口径节约 | 251 |
| 减：机器人电费、维保、配件（增量投资约 $1,200 万的 12%/年） | −144 |
| **进入 EBITDA 的净节约** | **约 107** |
| 另：加班、流失重聘、重复培训少发生（不进主表） | 80–120 |
| **运营口径合计改善** | **约 190–230 万 / 年** |

增量机器人投资约 $1,200 万（人形门禁、送餐机、食堂与洗衣线；停车机器人已含在 7.1.2 停车楼 $2,800 万内），按净节约 $190 万计，**回收约 6 年**；若含加班与流失，回收约 **5 年**。不把该节约写入第七章主表，作为 V1.2 管理预算的降本目标。

### 12.5.3 质量与安全边界

- 厅内赌台、监察、筹码房：**零机器人替代**。
- 国宾楼层、总统套房走廊：真人安保为主，机器人只做辅助巡视。
- 医疗：机器人不诊断、不给药。
- 所有机位纳入 CMS / 楼宇网，日志保存不少于 7 年，接受 GRA 抽查。

## 12.8 对政府就业承诺的一句实话

第十章 4,100 人、本地 73.8% 仍是**对社会与 IMF 就业叙事的上限承诺**。V1.2 用机器替换的是重复劳动，不是把本地就业“做小”：

- 对外继续按 4,100 人规划培训与社区岗位；
- 对内按 3,690 人排班、发薪；
- 差额用本地技师培训、供应商驻场、高峰兼职消化；
- 人均薪酬因技能上移而提高，个税基数不必同比下降。
